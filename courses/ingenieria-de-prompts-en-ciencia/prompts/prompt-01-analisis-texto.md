# Prompt 01 – Análisis de texto científico

## Contexto

Este prompt se utiliza para analizar textos científicos desde una
perspectiva epistemológica y metodológica, sin delegar el juicio
crítico a la IA.

## Prompt

> Actúa como asistente académico especializado en análisis epistemológico.
> Analiza el siguiente texto identificando:
> - problema de investigación
> - marco teórico
> - tipo de inferencia
> - supuestos implícitos
> No agregues información externa ni opiniones personales.

## Uso recomendado

- revisión de literatura
- curación académica
- entrenamiento en lectura crítica
